# Credential logging remediation

Deploy and verify the write filters before rotating any credential. Rotation
through an audited model must not record the replacement secret.

## New writes

- Model activity logging excludes credential fields. The configured ActivityLog
  model also redacts nested properties, Setting/UserMeta values, and credentials
  expanded into descriptions. Credential-only changes retain actor/subject/event
  metadata without storing their values. Use the configured activity model or `activity()`;
  direct SQL inserts and third-party log writers are outside these hooks.
- The legacy logger and configured Laravel log channels, including emergency
  fallback, redact credentials. Request IDs are generated by the server; client
  X-Request-ID headers are not copied into log prefixes.
  Exceptions retain class, code and call locations, not argument values. Settings
  SQL, password recovery material, SMTP configuration and email bodies must not be
  logged at their source.
- The bundled OpenResty access log records method, protocol, status, byte count,
  timing, source address and generated request ID. It deliberately excludes URI,
  query string, request body, cookies, authorization and Referer. Passkey login
  URLs contain credentials in the path, so replacing `$request` with `$uri` is not
  sufficient. Unknown HTTP methods are logged as `OTHER`, since even
  the method token is client-controlled.

For a native Nginx installation, install this format in the `http` context and
select it in **every** server/location serving the site, including redirects and
tracker endpoints. Check inherited and multiple access logs before reloading.

```nginx
map $request_method $nexus_log_method {
    default OTHER;
    GET GET;
    HEAD HEAD;
    POST POST;
    PUT PUT;
    PATCH PATCH;
    DELETE DELETE;
    OPTIONS OPTIONS;
    CONNECT CONNECT;
    TRACE TRACE;
}
log_format nexus_safe '$remote_addr [$time_iso8601] "$nexus_log_method $server_protocol" '
                      '$status $body_bytes_sent "$request_id" $request_time';
access_log /var/log/nginx/nexus-access.log nexus_safe;
```

Native Nginx error logs append a raw request URI even without debug logging.
For a host using rsyslog, install `deploy/rsyslog/15-nexus-nginx-errors.conf`
(the `imuxsock` module must already be loaded), create the output log with the
host's rsyslog owner and mode `0640`, validate with `rsyslogd -N1`, then restart
rsyslog and confirm its dedicated socket exists before changing Nginx:

```nginx
error_log syslog:server=unix:/var/log/nginx/nexus-error.sock,facility=local6,tag=nexus_error,nohostname warn;
```

Apply this to all site servers, including redirects and tracker endpoints. The
dedicated input ruleset writes only timestamp, severity, fixed error category,
fixed PHP exception type and Nginx connection number. It never writes raw exception
messages or request context, and does not forward them to default syslog rules.
Arbitrary PHP source paths and line numbers are not extracted from this stream:
request headers and exception messages can spoof those fields. Detailed
application diagnostics remain available through the PHP redactor.
Do not configure a disk-backed queue or a raw forwarding action before this
filter. Ensure log rotation preserves rsyslog's output-file ownership and sends
rsyslog HUP so it reopens its file. Validate with
`python3 tests/Integration/native_log_security.py` on an isolated Linux host with
Nginx and rsyslog installed; the test requires root for its temporary paths and
uses only loopback HTTP and a private Unix socket.

The bundled OpenResty access format alone does not sanitize its stderr error
log; deployments must configure the equivalent collector before claiming that
boundary is protected. External proxies, database general logs and arbitrary
third-party output remain separate inventories.

IP access history retains user/IP/count and known static PHP endpoint names;
dynamic paths are recorded as `/[dynamic-route]`. Query strings are omitted.
This filter applies both when buffering in Redis and when flushing to the DB.
Before deployment, preserve a restricted snapshot of existing `nexus_ip_logs:*`
Redis buffers, since the normal scheduled flush consumes them. This does not
redact existing database history.

## Existing audit evidence

Do not delete the audit table or attach credential-bearing evidence to Git,
issues or pull requests. Use a restricted directory outside the application and
Web roots. Preserve the original export, checksum, capture time and custody
information under the incident's retention policy.

The following command first writes all audit rows through a fixed maximum ID to
an exclusive new JSONL file with mode `0600`. It flushes and verifies a SHA-256
checksum **before** updating any row. Without `--apply`, it only makes the backup.

```bash
php artisan security:redact-activity-log --backup=/secure/evidence/activity-unique.jsonl --apply
```

Use a new evidence filename for every run. Protect and verify the evidence outside
the host as appropriate for the incident. `--apply` preserves IDs, actor/subject
metadata, event types and timestamps; it replaces sensitive log copies, not the
business credentials. Rows changed concurrently are skipped and cause failure,
so investigate and rerun with a new snapshot. Keep evidence even if a later row
cannot be processed. Historical Setting/UserMeta value-only rows lacking the
original setting name are conservatively redacted because the subject may have
been renamed or deleted since the event.

Historical web/application logs need a separate restricted original copy and
reviewed redacted working copy. Do not edit or remove the only original. Database
backups, rotated/compressed logs, log forwarding and existing exports are part of
the evidence inventory. Removing a secret from current logs does not revoke it.

After new-write tests and deployment are verified, inventory exposed live keys,
rotate/revoke them through the correct authentication workflows, invalidate
affected sessions as appropriate, then check that replacement values did not
appear in any configured sink. Do not print either old or new values during the
verification; report aggregate counts and synthetic-canary results.
